# Data directory

- `sample/cases.csv` - **synthetic placeholder** (12 rows) used only to verify that the pipeline runs end to end. It does **not** describe real companies and must not be interpreted as evidence.
- `sample/coder_agreement.csv` - synthetic double-coding of DV1 for the inter-coder agreement check.
- `raw/test_run.jsonl` - raw latency benchmark log: line 1 is run metadata, then one JSON record per run (phase = warmup | work). Generated by `python -m src.benchmark`.
- `processed/metrics_summary.csv` - aggregated latency statistics produced by `src/process_data.py`.

Column dictionary: see `docs/codebook.md`.
