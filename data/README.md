# Data directory

- `sample/cases.csv` - **synthetic placeholder** (12 rows) used only to verify that the pipeline runs end to end. It does **not** describe real companies and must not be interpreted as evidence.
- `sample/coder_agreement.csv` - synthetic double-coding of DV1 for the inter-coder agreement check.
- `raw/test_run.jsonl` - small synthetic latency benchmark log: line 1 is metadata, then warm-up and evaluation records (`phase = warmup | work`). Generated by `python -m src.benchmark`.
- `processed/metrics_summary.csv` - per-workload latency/throughput percentiles, seeded bootstrap confidence intervals, and error counts produced by `src/process_data.py`.
- `processed/benchmark_guardrails.csv` - unexpected error-rate guardrail; expected invalid-input test failures remain counted separately.

These timing results profile the local analysis function against synthetic inputs.
They are not production evidence or a baseline-versus-proposed runtime comparison.
Column dictionary for the research cases: see `docs/codebook.md`.
